# Ressources Cuivre & Azur conservées

- `icones.png` : ancien atlas original conservé, 4 × 4 cases ; bijoux,
  flamme, protection, livre, cristal, vitalité, sablier, magie et plume.
  Source : `exec-21ba8482-1ff8-4283-8545-02285b9cdd8f.png`.
- `glyphes/` : SVG natifs réemployés par les augments et passifs, générés par
  `tools/refonte_svg.py`. Les bases illustrées et les gravures propres à chaque
  capacité remplacent les anciennes vectorisations peintes.
- Les bijoux et armes utilisent les SVG de `assets/visual/interface/equipement/`
  et `armes/`, générés avec le même kit.
- `tools/generer_icones.py` fournit les motifs historiques ; utiliser
  `tools/refonte_svg.py` pour régénérer le kit actif. L'ancien outil de
  vectorisation peinte est archivé hors dépôt.

L'ancien accueil et le calcaire de cette direction ont été archivés dans
`../OldAlambik/2026-09-20/retires/` depuis la racine du projet. Aucun asset d'un
autre jeu n'a été repris.
