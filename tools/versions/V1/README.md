# V1 — charte actuelle avant la refonte vive

Instantané des sources de style, des composants d’accueil, des cadres SVG actifs
et de la direction artistique présents avant la création de la V2.

Les chemins sous ce dossier reprennent les chemins d’origine du projet. Pour
restaurer un élément, recopier son équivalent de `V1/` vers le chemin relatif
correspondant à la racine du projet. Les sources SVG se trouvent dans
`tools/design_svg/` et `tools/refonte_svg.py` ; les rendus actifs sont dans
`assets/visual/interface/`.
