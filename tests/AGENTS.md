# tests/

Tests déterministes. Commencer par la suite correspondant au module modifié ; ne lire toutes les suites que pour le harnais lui-même.

Créer ou exécuter des tests seulement sur demande explicite, conformément à l'`AGENTS.md` racine.
Lorsqu'un test est demandé, préférer une régression ciblée sans partie complète. Les mesures de runs appartiennent plutôt à `sondes/`.
