# Documentation

`INDEX.md` oriente, `CURRENT.md` décrit brièvement l'état vérifié,
`design/GAME_DESIGN.md` décrit le périmètre actif, et
`design/DIRECTION_ARTISTIQUE.md` porte les décisions visuelles.

Ne pas recopier des catalogues dans ces documents. Les listes chiffrées pour
le propriétaire sont dans `statistiques_jeu/` et se régénèrent depuis le jeu.
Les index routent les agents vers un fichier, un symbole et un contrôle ; ils
ne remplacent pas les sources. Actualiser les liens lors d'un déplacement.
Distinguer une règle implémentée, une mesure automatisée et un ressenti qui
reste à tester sur appareil. Supprimer les affirmations rendues fausses par
la modification plutôt qu'empiler des notes chronologiques.
